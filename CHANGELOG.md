# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-14

### Added
- Chromatic tuner with cents gauge, strobe-style band and tuning guidance.
- Presets for guitar (standard, Drop D, half step down), 7-string guitar, 4- and 5-string bass,
  cavaquinho, ukulele and violin, with automatic string detection and string locking.
- Adjustable A4 reference (415–466 Hz) and reference tone generator.
- Letter and solfège note names, three sensitivity levels.
- English and Portuguese translations.
- Pitch detector based on harmonic scoring of FFT peaks, with tests on synthetic signals.
